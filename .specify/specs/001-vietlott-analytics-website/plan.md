## Data Pipeline

### Input (JSONL from crawler)
```
data/power655.jsonl → Matrix format: result is number array
data/3d.jsonl       → 3D format: result is {tier: [strings]}
```

### Processing (`scripts/build_data.py`)
1. Read each JSONL with polars
2. Normalize dates to ISO 8601 strings
3. Sort descending by date
4. Output compact JSON to `website/public/data/`

### Output JSON Schema

**Matrix products:**
```json
{
  "meta": {"product": "power_655", "totalDraws": 1326, "startDate": "2017-08-01", "endDate": "2026-04-17"},
  "draws": [
    {"date": "2026-04-17", "id": "01326", "result": [7, 13, 21, 30, 33, 39], "special": 35}
  ]
}
```

**3D products:**
```json
{
  "meta": {"product": "3d", "totalDraws": 1064, "startDate": "2019-04-22", "endDate": "2026-04-17"},
  "draws": [
    {"date": "2026-04-17", "id": "01064", "result": {"special": ["015","517"], "first": ["334","279","576","060"], "second": ["043","900","132","916","370","766"], "third": ["634","573","539","048","967","262","523","185"]}}
  ]
}
```

## Suggestion Engine (TypeScript port)

Port logic from `src/vietlott/cli/suggest.py`:

### Matrix Strategy
1. **Frequency-based:** Weight numbers by historical frequency, sample weighted
2. **Long Absence:** Prioritize numbers with longest gap since last appearance
3. **Mixed:** 50% from hot pool + 50% from cold pool for diversity

### 3D Strategy
1. **Top Frequency:** Pick from most common 3-digit numbers
2. **Digit Composition:** Independently pick each digit (H/T/U) by frequency
3. **Long Absence:** Pick 3-digit numbers that haven't appeared longest
